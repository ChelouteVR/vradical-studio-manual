VRadical Studio

A desktop application for professional immersive video and photo processing on macOS and Windows.

Open User Manual

What the application does

Create finished immersive media from supported camera originals.

VRadical Studio imports supported VR camera videos and photos, corrects stereo alignment, calibrates and stabilizes immersive footage, provides timeline editing and image controls, and exports finished VR media for viewing and publication.

Local media production

Source media is processed on the user's computer. Studio provides camera-aware calibration, stabilization, stereo correction, color and image controls, audio processing, timeline editing, preview, and export. The User Manual documents the complete workflow.

Optional YouTube publishing

When a user chooses to connect YouTube, Studio requests Google authorization to identify the user's YouTube channel and upload an exported video with the title, description, category, visibility, scheduling, and other publication settings selected by that user. Google user data is not used for advertising or unrelated purposes. See the Privacy Policy.
